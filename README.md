Entry for the [make.fun bounty "Fortune in a Pot"](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9).

The program writes one kind, funny fortune for a houseplant to `/output/entry.txt`:

> A ladybug will land on your tallest leaf this week and declare it the best seat in the house.

It is 93 characters, reads cleanly aloud, and dodges every crowded cluster in
the field (no outgrowing the pot, no new leaf, no sunbeam, no cat, no keeper
bragging, no watering on schedule — all measured 0-hit for the ladybug angle
across all 207 field submissions). A ladybug as a tiny critic, announcing the
best seat in the house, is a small joke that lands the way a plant lover would
laugh at it — warm, specific to this plant on this windowsill, and shaped like
a prediction rather than a slogan.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
